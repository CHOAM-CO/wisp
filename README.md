# Quest MR Gaze-Centered Companion

Meta Quest 3 패스스루 공간에 상주하며 사용자와 상호작용하는 **가상 실물형 에이전트(Virtual Presence)**와, 별도 안구 추적 하드웨어 없이 **"사람은 관심 있는 대상을 결국 시야의 중심으로 가져온다"**는 행동 특성을 역이용한 **시선 중심 관심도 기반 메모리·대화·추천 시스템** 프로젝트입니다.

상세 기획 및 시스템 아키텍처는 [`docs/PLAN.md`](docs/PLAN.md)에 정리되어 있습니다.

---

## 핵심 콘셉트 요약

1. **그래픽 상호작용 에이전트 가상 실물 & 무컨트롤러 이중 손 인식**
   - 패스스루 현실 공간에 떠 있는 3D 에이전트 실체(연기 정령 프로토타입)가 시선 방향과 손길에 즉각 반응하며, Horizon OS Seamless Multitasking(2D 창 앱 동시 사용) 중에도 멈추지 않고 공존합니다.
   - **핸드 기기(컨트롤러) 없이도 완전 동작**: ① OpenXR 26관절 맨손 추적(`XRHandTracker`, 핀치 및 검지 공간 룬 터치)과 ② 패스스루 RGB 카메라 기반 `MediaPipe HandLandmarker`(21 키포인트 손·핀치 검출)를 함께 구현해 컨트롤러 없이 맨손만으로 정령 터치·추천 호출·디버그 토글이 모두 가능합니다.
2. **무안구추적(Eye-Tracking-Free) 시야 중심 관심도 추정**
   - AR 글라스나 Quest 3처럼 안구 추적이 없는 환경에서, 착용에 익숙해질수록 관심 대상을 무의식적으로 시야 정중앙으로 가져오는 습관을 역이용합니다.
   - 실시간 객체 탐지·추적 중 **(a) 시야 진입 후 중심부 도달 시간**과 **(b) 중심부 체류 시간** 등으로 관심도 점수를 매겨, 임계치 이상인 물체만 캡처와 함께 **중단기 메모리**로 넘기고 나머지는 즉시 폐기합니다.
3. **경량 어노테이션 · EmbeddingGemma 2 인덱싱 · 장기 메모리 승격**
   - 중단기 메모리 진입 시 저가(경량) 모델로 텍스트 어노테이션을 부착하고, **EmbeddingGemma 2**로 임베딩 인덱싱해 어노테이션과 함께 저장합니다.
   - 이후 실제 검색(Retrieval)에서 호출·활용된 기억만 **장기 메모리**로 승격합니다.
4. **하이브리드 검색 (벡터 Top-3 + 단어 Top-3) 및 대화·추천**
   - 검색 시 **벡터 서치 상위 3개**와 **단어 기준 검색 상위 3개**를 함께 반환해 일상 대화 소재와 추천 맥락에 활용합니다.
   - 상품/쇼핑 추천 시에는 시야 피로와 선택 부담을 줄이기 위해 **딱 2가지 추천 예시만** 제시합니다.

## 데모 사용자 설정 및 프로덕트 설계 주석

해커톤 데모에서는 시연 및 비교를 위해 아래 **2가지 개입 모드 설정**을 제공합니다.

1. **항상 추천, 바로바로 추천**: 관심 임계치를 넘거나 연관 맥락이 포착되면 즉시 먼저 말을 걸어 제안
2. **물어봤을 때만 검색 후 제안**: 평소에는 관심 기억만 조용히 쌓아두고, 사용자가 물어봤을 때만 검색 후 제안

> **Note (Demo-Only Configuration)**  
> 위 두 가지 추천 모드를 사용자 설정으로 분리한 것은 **데모 시연을 위한 구성**이며, 실제 프로덕트에서는 사용자 설정으로 두지 않습니다. 실제 제품에서는 별도 설정 선택 없이 에이전트가 사용자의 시선 집중도와 상황 맥락에 따라 개입 여부와 타이밍을 스스로 조절합니다. (이 설명은 인앱 UI에는 표기하지 않고 레포지토리 문서에만 기록합니다.)

## 데모 시연용 컨트롤러 버튼 매핑 (X-Ray 렌더링 토글)

실사용 환경에서는 패스스루 시야를 가리지 않도록 내부 탐지·메모리 과정이 숨겨져 있으며, 시연 및 녹화 시 **컨트롤러 조이스틱 옆 버튼들**을 눌러 내부 동작을 실시간 오버레이로 토글할 수 있습니다.

- **오른손 `A` 버튼**: **객체 탐지 Bounding Box + 시야 중심 반경(Center ROI) + 실시간 관심도 점수 오버레이** ON/OFF 토글
- **오른손 `B` 버튼**: **메모리 파이프라인(저가 모델 어노테이션 · EmbeddingGemma 2 · 장기 메모리 승격) 및 하이브리드 검색(벡터 Top-3 / 단어 Top-3) 인스펙터** ON/OFF 토글
- **왼손 `X` 버튼**: 데모 개입 모드 전환 (`항상 바로바로 추천` ↔ `물어봤을 때만 검색 후 제안`)
- **왼손 `Y` 버튼**: 음성 질의 / 추천 요청 트리거 (시연장 소음 대비 Push-to-Talk, 길게 누르면 데모 리셋)

## 개발 환경 및 실기기 실행 (Meta Quest 3)

- **엔진**: Godot 4.7.2 + `godot_openxr_vendors` (5.1.0-stable)
- **Android 빌드 요구사항**: OpenJDK 21, Gradle 8, Android SDK Platform 36 / Build-Tools 36.1.0

Quest 3가 USB로 연결되고 ADB 디버깅이 허용된 상태에서 원클릭 빌드·설치·실행:

```bash
./deploy.sh
```

에디터 열기:

```bash
/Applications/Godot-4.7.2.app/Contents/MacOS/Godot --editor project.godot
```
